Build a new background

Neon Stage exposes a small, stable shader contract. Add one Unity shader, register one catalog entry, and receive smoothed music bands, bass transients, and the seek-safe song clock every frame.

Shaders are compiled into the Stage build. Neon Stage never downloads executable shader code from the server, which keeps Linux and Android releases deterministic and reviewable.

Quick integration

  1. Create Assets/Resources/BackgroundShaders/MyBackground.shader inside src/Karaoke.Stage.Unity.
  2. Use a unique shader name such as NeonStage/Background/MyBackground.
  3. Declare any shared music properties your effect needs.
  4. Add a stable ID and resource path to Assets/Resources/NeonStageBackgrounds.json. Omit the file extension.
  5. Build and launch the Stage with the new ID.
{
  "id": "my-background",
  "displayName": "My Background",
  "resource": "BackgroundShaders/MyBackground"
}
./scripts/linux/build-unity-stage-linux.sh
./scripts/linux/start-unity-stage.sh --background-shader my-background

# Equivalent Linux environment variable:
NEONSTAGE_BACKGROUND_SHADER=my-background \
  ./scripts/linux/start-unity-stage.sh

The music contract

The Stage checks every property before writing it, so a shader may implement only the inputs it consumes. Property names are case-sensitive.

PropertyValueUse
_Energy0–1Smoothed full-spectrum energy
_Bass0–1Low-frequency movement and weight
_Mid0–1Voice, guitars, and central musical motion
_Treble0–1High-frequency detail and sparkle
_Pulse0–1Fast bass onset followed by a short decay
_SongTimesecondsPlayback position that follows pause, resume, and seek
_IsPlaying0/1Whether the audio clock is running

Bands are normalized against decaying local peaks, making one shader respond sensibly to quiet and heavily mastered tracks. For transport-synchronized motion use _SongTime; Unity's _Time continues while paused.

Minimal shader

Shader "NeonStage/Background/MyBackground"
{
 Properties {
  _Energy("Energy",Range(0,1))=0
  _Bass("Bass",Range(0,1))=0
  _Pulse("Pulse",Range(0,1))=0
 }
 SubShader { Tags { "Queue"="Background" }
  Cull Off ZWrite Off ZTest Always
  Pass { CGPROGRAM
   #pragma target 3.0
   #pragma vertex vert
   #pragma fragment frag
   #include "UnityCG.cginc"
   struct appdata { float4 vertex:POSITION; float2 uv:TEXCOORD0; };
   struct v2f { float4 vertex:SV_POSITION; float2 uv:TEXCOORD0; };
   float _Energy,_Bass,_Pulse;
   v2f vert(appdata v){v2f o;o.vertex=UnityObjectToClipPos(v.vertex);o.uv=v.uv;return o;}
   fixed4 frag(v2f i):SV_Target {
    float2 p=i.uv*2-1;
    p.x*=_ScreenParams.x/_ScreenParams.y;
    float glow=exp(-length(p)*(3-_Bass));
    float ring=exp(-abs(length(p)-(.3+_Pulse*.12))*24);
    float3 col=float3(.018,.004,.035);
    col+=glow*float3(.45,.02,.6)*(.2+_Energy);
    col+=ring*float3(.85,1,.03);
    return fixed4(col,1);
   }
  ENDCG }
 }
}

The repository includes NeonPulseRings.shader as a complete example using all bands and the song clock.

Selection and Android

Selection priority is command line, NEONSTAGE_BACKGROUND_SHADER, Unity PlayerPrefs key NeonStage.BackgroundShader, then the catalog's defaultId. Unknown IDs fall back safely to the default.

Android launchers normally cannot provide environment variables. Set defaultId in the JSON catalog before building the APK. This keeps the same shader contract available for a future Stage settings screen.

Performance and readability

  • Keep the central lyric area dark and reserve bright values for short accents.
  • Use _Pulse sparingly; repeated full-screen flashes hurt readability.
  • Prefer smooth functions over divergent branches and cap every loop.
  • Begin with shader target 3.0 and test the ARM32 Android build on real hardware.
  • Return opaque color and avoid implicit network or cover-art dependencies.
  • Check licenses before including third-party shader code.

Validation and troubleshooting

  1. Check the Unity console for compile errors.
  2. Verify idle, countdown, playback, pause, resume, and seek.
  3. Test quiet and loud masters and keep lyrics, QR code, next-song card, and controls readable.
  4. Inspect the player log for Neon Stage background shader:.

A pink screen means Unity found the asset but could not compile it for the active graphics API. A silent fallback to Neon Grid usually means the catalog ID or resource path is wrong. If animation works but ignores playback, verify the exact property names and use _SongTime instead of _Time.
