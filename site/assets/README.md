# Website asset provenance

`stage-demo.png` and `editor-demo.png` are real captures of the current Neon
Stage Unity application and Avalonia Lyrics Editor, recorded on 2026-07-27.
Both applications were connected to an isolated temporary server and a
synthetic two-track demo library, never to a production media library.

Safety constraints used for both images:

- no real song titles, artist names, lyrics, or cover artwork;
- locally generated test audio instead of copyrighted recordings;
- no people or third-party logos;
- project-owned Neon Stage artwork as the cover;
- neutral `Demo Track A` / `Demo Track B` and `Neon Stage` metadata;
- the standard pangram “The quick brown fox jumps over the lazy dog.” as the
  only lyric-like sentence.

The screenshots are distributed with the project under its Apache-2.0 license
to the extent applicable. The Neon Stage name and branding remain subject to
the trademark limitation stated in the project license documentation.
