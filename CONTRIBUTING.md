# Contributing

Thank you for helping Neon Stage. Open an issue before a large change and keep pull requests focused. Build and test affected .NET projects and, for Stage changes, verify the Unity Linux and Android targets.

Contributions must be your own work or compatible third-party material with complete provenance and notices. Do not submit songs, stems, lyrics, cover art, credentials, databases, user data, model weights or generated caches. Unless explicitly stated otherwise, intentionally submitted contributions are provided under Apache-2.0 as described by section 5 of the project license.
