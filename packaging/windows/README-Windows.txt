NEON STAGE FOR WINDOWS
======================

Server
------
Start-NeonStage-Server.cmd starts the server on port 5274. By default it uses:

  Library:  %USERPROFILE%\Music\NeonStage
  Database: %LOCALAPPDATA%\NeonStage\server\karaoke.db
  Cache:    %LOCALAPPDATA%\NeonStage\server\usdb-cache

Set Karaoke__LibraryPath, Karaoke__DatabasePath, Usdb__CachePath,
Karaoke__PublicBaseUrl or ASPNETCORE_URLS before starting the CMD file to
override these values. Use the LAN/HTTPS address as Karaoke__PublicBaseUrl when
guest phones must open invitations generated by this server.

Lyrics Editor
-------------
Start-NeonStage-Editor.cmd connects to http://127.0.0.1:5274 by default. Set
KARAOKE_SERVER before starting it to use another server.

Stage
-----
Start NeonStage.exe. Set KARAOKE_SERVER or NEONSTAGE_SERVER_URL, or pass
--server http://SERVER:5274 when a different server should be used.

All packages are portable. Keep every file within its extracted directory.
Do not run applications directly from inside the ZIP archive.
